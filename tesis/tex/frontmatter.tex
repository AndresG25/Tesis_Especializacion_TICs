\chapter*{Resumen}
\addcontentsline{toc}{chapter}{Resumen}

En este trabajo se propone, desarrolla y valida una arquitectura para adquirir, transmitir, almacenar, procesar y visualizar datos de un generador eólico de pequeña escala. La solución integra un subsistema embebido distribuido basado en tarjetas ESP32-C6, comunicación local entre nodos, datos en formato json, publicación segura mediante MQTTs hacia AWS IoT Core y una capa de almacenamiento y consulta soportada en servicios serverless de AWS.

El sistema de adquisición se organiza en tres etapas: un nodo de campo que mide variables del generador, un nodo integrador local que consolida variables ambientales y operativas y estructura el mensaje de telemetría, y un gateway IoT encargado de la conectividad Wi-Fi, la sesión MQTT segura y la publicación de datos hacia la nube.

En la capa cloud, la arquitectura usa AWS IoT Core para la ingesta MQTTs, DynamoDB para conservar el último dato por dispositivo, S3 como repositorio histórico, Glue y Athena para catalogar y consultar series temporales, Lambda como API serverless y un dashboard React/Vite servido mediante S3 y CloudFront. Esta separación distingue la ruta de datos casi en tiempo real de la ruta histórica, reduciendo costos y facilitando la escalabilidad.

La contribución principal es una metodología reproducible para instrumentar, transmitir y analizar datos de pequeños sistemas eólicos integrando IoT, cloud computing y Big Data, con trazabilidad desde la sensórica y el firmware hasta la visualización web y la validación experimental.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This work proposes, develops and validates an architecture to acquire, transmit, store, process and visualize data from a small-scale wind generator. The solution integrates a distributed embedded subsystem based on ESP32-C6 boards, local communication between nodes, data in json format, secure MQTTs publication to AWS IoT Core, and a storage and query layer supported by AWS serverless services.

The acquisition system is organized into three stages: a field node that measures generator variables, a local integration node that consolidates environmental and operational variables and structures the telemetry message, and an IoT gateway responsible for Wi-Fi connectivity, the secure MQTT session and data publication to the cloud.

In the cloud layer, the architecture uses AWS IoT Core for MQTTs ingestion, DynamoDB to keep the latest value per device, S3 as the historical repository, Glue and Athena to catalog and query time series, Lambda as a serverless API, and a React/Vite dashboard served through S3 and CloudFront. This separation distinguishes the near-real-time data path from the historical path, reducing costs and facilitating scalability.

The main contribution is a reproducible methodology to instrument, transmit and analyze data from small wind systems by integrating IoT, cloud computing and Big Data, with traceability from sensors and firmware to web visualization and experimental validation.

\textbf{Keywords:} ESP32-C6, IoT, MQTT, TLS, AWS IoT Core, Big Data, DynamoDB, Amazon S3, Athena, Lambda, wind generation, embedded systems, web dashboard.
