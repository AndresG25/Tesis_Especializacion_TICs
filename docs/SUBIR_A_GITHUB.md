# Subida desde RStudio

La tesis y los tres proyectos ESP se administran ahora juntos. El procedimiento vigente está en [INICIAR_EN_RSTUDIO.md](INICIAR_EN_RSTUDIO.md).

Clone `https://github.com/AndresG25/Tesis_Especializacion_TICs.git` desde **New Project → Version Control → Git**, copie dentro del clon el contenido del ZIP integrado y abra el `.Rproj` de la raíz. Revise las diferencias, haga Commit y luego Push.

Esta entrega no publicó cambios en GitHub. El paquete no contiene una carpeta `.git`; se utiliza la que crea la clonación para mantener la historia del repositorio.
